# Plateforme e-commerce de coques de téléphone

Ce projet est une boutique en ligne spécialisée dans la vente de coques de téléphone, réalisée dans le cadre du cours de NoSQL.
Le client peut consulter le catalogue, remplir son panier et passer commande.
Il reçoit des recommandations de produits adaptées à son modèle de téléphone.
Un service de livraison permet de suivre l'avancée de chaque colis, et un service après-vente gère les retours et les réclamations
